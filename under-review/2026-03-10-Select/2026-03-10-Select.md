# Select

Most pi calculi have some notion of "summation" where only one of the summed processes gets to execute.  Rholang restricts it to sums of inputs, so it is called "selection" rather than "summation":

```
select {
  <ptrn_11> <- <name_11> & ... & <ptrn_1k> <- <name_1k> => <proc_1>
  ...
  <ptrn_n1> <- <name_n1> & ... & <ptrn_nm> <- <name_nm> => <proc_n>
}  
```

As soon as one of the contained `join => continuation` clauses matches, the corresponding continuation gets executed and the rest are discarded.  Only the linear arrow is supported.

## Reified RSpaces

To support selection, the space agent needs an extra method:

```
// Implements selection
// - listClause is a list of join/continuation clauses where
//   - the join is a list of pairs (m, c) of processes where
//     - m is a matcher that takes a process to match and returns  
//       either None or Some(env), where env is a map from  
//       string to process  
//     - c is a channel to listen on
//   - the continuation is a process expecting a map from strings to processes
// May abort.
method select(listClause) { ... }  
```
